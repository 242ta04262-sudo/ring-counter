description
A Ring Counter is a type of shift register in which the output of the last flip-flop is connected back to the input of the first flip-flop.

In this project, a 4-bit Ring Counter is implemented using Verilog.

The counter circulates a single 1 through the four flip-flops:

Features
4-bit Ring Counter
Synchronous counter operation with clock
Asynchronous reset
Verilog HDL implementation
Testbench included
Easy to simulate using Icarus Verilog
Suitable for learning RTL and digital design
